  3.1  standalone: false ADDED TO 370 COMPONENT FILES
  -----------------------------------------------------
  Angular 19 changed the default: standalone now defaults to TRUE.
  All existing non-standalone components/directives/pipes need explicit
  "standalone: false" - otherwise Angular 19 treats them as standalone.

  BEFORE (Angular 18):
    @Component({
      selector: 'app-foo',
      templateUrl: './foo.component.html'
    })

  AFTER (Angular 19):
    @Component({
      standalone: false,              <-- ADDED
      selector: 'app-foo',
      templateUrl: './foo.component.html'
    })

================================================================================
SECTION 5 : WHY EACH CHANGE WAS NEEDED
================================================================================

  CHANGE                        WHY
  --------------------------    ------------------------------------------------
  Browser builder removed       Angular 19 removed old Webpack builder.
                                Must use application builder (ESBuild/Vite)

  standalone: false             Angular 19 changed default: standalone = true.
                                All old NgModule components need explicit false.

  zone.js 0.14 → 0.15          Angular 19 requires zone.js 0.15 minimum.

  TypeScript 5.4 → 5.6          Angular 19 requires TypeScript 5.5 or 5.6.

  moduleResolution: bundler     ESBuild uses bundler resolution. "node" is
                                deprecated in TS 5.6 with ESBuild projects.

  allowSyntheticDefaultImports  Needed for default import of CommonJS modules
  + esModuleInterop             like moment.js and jszip.

  ~ removed from CSS imports    ~ prefix was Webpack-only feature.
                                ESBuild does not support it.

  'string' || 'string' fixed    TypeScript 5.6 made always-truthy string
                                literals a hard error (TS2872).

  moment import fixed           ESBuild treats namespace imports differently.
  (import * as → import)        Default import is the correct way with
                                esModuleInterop enabled.
